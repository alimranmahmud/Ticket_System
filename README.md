 - What is JSX, and why is it used?
 JSX, or JavaScript XML, lets you write HTML-like code inside JavaScript.It is mainly used in React to create user interfaces.



 - What is the difference between State and Props?

Props: Short for "properties," props are used to pass data from a parent component to a child component. They are read-only and state is a local data storage that is managed within a component. It can change over time, usually in response to user actions.



 - What is the useState hook, and how does it work?

The useState hook is a built-in React hook that lets functional components have state, which was only possible in class components before hooks. It allows you to store and update data that can change over time, like input values, counters, or toggles.

 - How can you share state between components in React?
 Move the shared state to the closest common parent of the components that need it.
 Pass the state and updater function as props to child components.


 - How is event handling done in React?
Events are written in camelCase, not lowercase like HTML.Instead of a string, you pass a function as the event handler.
